# VibeWave v2.0.0

Premium music streaming app with YouTube integration, Firebase backend, and cutting-edge social listening features.

## What's New in v2.0.0

- Audio Quality Selection (Auto/Low/Medium/High/Highest 320kbps+)
- Listen Together - Real-time social listening rooms via Firestore
- Waveform Visualizer - Animated 20-bar waveform in Now Playing
- 5-Band Equalizer with 7 presets (AndroidEqualizer from just_audio)
- Sleep Timer (15/30/45/60/90 min)
- Speed Control (0.5x-2.0x) and Pitch Control
- Crossfade between tracks (0-10 seconds)
- Skip Silence feature
- Synced Lyrics (line-by-line highlight)
- Listening History (local, via Hive, last 50 songs)
- Settings Screen (quality, EQ, sleep timer, crossfade, speed)
- Queue Reordering with drag-to-reorder
- New Sound-wave App Icon (purple #6C63FF to cyan #00D9FF)
- Together nav item in bottom bar

## Getting Started

flutter pub get
flutter run
