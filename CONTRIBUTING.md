# Contributing to VibeWave / BeatStream

Thank you for your interest in contributing! We welcome all contributions to improve this open-source Flutter music streaming application.

## 📋 Code of Conduct

Please be respectful, collaborative, and constructive when interacting with maintainers and other contributors.

## 🚀 How to Contribute

### 1. Reporting Bugs
- Search existing issues to ensure the bug hasn't already been reported.
- Create a detailed issue including:
  - Device model and OS version (Android/iOS)
  - Flutter version (`flutter --version`)
  - Steps to reproduce
  - Expected vs actual behavior
  - Log output or error messages

### 2. Suggesting Features
- Open a feature request issue describing:
  - The feature and its intended use case
  - How it enhances user experience
  - Any proposed UI/UX or architectural designs

### 3. Submitting Pull Requests
1. **Fork** the repository and create your feature branch:
   ```bash
   git checkout -b feature/amazing-feature
   ```
2. **Ensure code quality**:
   - Run `flutter analyze` and ensure 0 issues are reported.
   - Run `flutter test` to ensure existing tests pass.
   - Follow Flutter and Dart style guides.
3. **Commit** your changes with clear, semantic commit messages:
   ```bash
   git commit -m "feat: Add playlist reordering support"
   ```
4. **Push** to your fork and submit a Pull Request targeting the `main` branch.

## 🛠️ Development Setup

1. Ensure you have Flutter SDK `>=3.24.0` installed.
2. Clone the repository and install dependencies:
   ```bash
   flutter pub get
   ```
3. Run static analysis:
   ```bash
   flutter analyze
   ```
4. Run on a connected Android device or emulator:
   ```bash
   flutter run
   ```

## ⚠️ YouTube & Audio Streaming Guidelines

- Do not bypass security features or implement circumvention tools.
- Please adhere to legal copyright guidelines and educational fair use principles.
